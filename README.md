# PageMemory

> Remember where you left off.

PageMemory is a Chrome extension built with React, TypeScript, Vite, and Tailwind CSS. This repository currently contains the Day 1 project foundation: Manifest V3 wiring, popup and options entry points, background service worker, and content script entry.

## Development

```bash
npm install
npm run dev
```

Load the unpacked `dist` directory in `chrome://extensions` after running a production build.

## Checks

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```
